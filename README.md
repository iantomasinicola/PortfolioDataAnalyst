# Portfolio Data Analyst: project work con SQL Server, Python ed Excel

Un project work completo di analisi dei dati, diviso in passi numerati: dall'obiettivo
del progetto alla dashboard finale. È pensato per chi vuole costruire un portfolio
da data analyst. La spiegazione completa è nell'articolo
[Portfolio Data Analyst](https://www.yimp.it/portfolio-data-analyst/).

## I passi del progetto

| File | Passo |
| --- | --- |
| 001_ObiettivoProgetto.docx | Obiettivo e domande a cui rispondere |
| 002_File Input.xlsx | Dati di partenza |
| 003_SetupDatabase.sql | Creazione del database su SQL Server |
| 004_DashboardExcel.xlsx | Dashboard in Excel |
| 005_OrchestrazionePython.py | Script Python che orchestra caricamento ed elaborazione |
| 006_OutputFinale.pdf | Risultato finale |
